# 商品

## 创建商品

```json
{
  "title": "纯棉 T 恤",
  "subtitle": "柔软透气",
  "description": "100% 纯棉",
  "categoryCode": "TSHIRT",
  "primaryImageFileId": "0195d7d2-6380-7a5c-8b35-3a23b8df1f01",
  "galleryImageFileIds": [
    "0195d7d2-6380-7a5c-8b35-3a23b8df1f02",
    "0195d7d2-6380-7a5c-8b35-3a23b8df1f03"
  ],
  "specifications": {
    "颜色": ["黑色", "白色"],
    "尺码": ["M", "L"]
  },
  "skus": [
    {
      "merchantSkuCode": "TSHIRT-BLACK-M",
      "price": 99.00,
      "imageFileId": "0195d7d2-6380-7a5c-8b35-3a23b8df1f04",
      "selections": {
        "颜色": "黑色",
        "尺码": "M"
      }
    },
    {
      "merchantSkuCode": "TSHIRT-WHITE-L",
      "price": 109.00,
      "imageFileId": "0195d7d2-6380-7a5c-8b35-3a23b8df1f05",
      "selections": {
        "颜色": "白色",
        "尺码": "L"
      }
    }
  ]
}
```

### 预处理

- 所有文本去除首尾空白。
- `galleryImageFileIds` 为 `null` 时转为空数组，忽略其中的 `null`，并按首次出现顺序去重。
- `specifications` 为 `null` 时转为空对象，忽略 `null` 规格名和 `null` 规格值，并对每个规格的值按首次出现顺序去重。
- 规格名称去除首尾空白后不得冲突，否则拒绝请求。
- `skus` 为 `null` 时转为空数组，忽略其中的 `null`。
- 有规格时，`selections` 为 `null` 时转为空对象，忽略键或值为 `null` 的选择；规格名称去除首尾空白后不得冲突。
- 无规格时，所有 SKU 的 `selections` 统一清理为空对象。

### 字段校验

有效文本：去除首尾空白后非空。

| 字段 | 必填 | 校验规则 |
| --- | --- | --- |
| `title` | 是 | 有效文本，最多 50 个字符 |
| `subtitle` | 否 | 有效文本，最多 50 个字符 |
| `description` | 是 | 有效文本，最多 5000 个字符 |
| `categoryCode` | 是 | 有效文本，最多 64 个字符 |
| `primaryImageFileId` | 是 | UUIDv7 |
| `galleryImageFileIds` | 否 | UUIDv7 数组 |
| `specifications` | 否 | 规格名称到规格值数组的有序映射 |
| `specifications` 的保留键 | 是 | 有效文本，最多 50 个字符 |
| `specifications` 的值 | 是 | 非空数组 |
| `specifications` 的保留值元素 | 是 | 有效文本，最多 50 个字符 |
| `skus` | 是 | 非空数组 |
| `skus[].merchantSkuCode` | 否 | 有效文本，最多 64 个字符 |
| `skus[].price` | 是 | `0 < price <= 99999999.99`，最多 2 位小数 |
| `skus[].imageFileId` | 否 | UUIDv7 |
| `skus[].selections` | 否 | 规格名称到规格值的映射 |
| `skus[].selections` 的保留键和值 | 是 | 有效文本，最多 50 个字符 |

### 约束

- 规格名称去除首尾空白后不冲突。
- 同一请求内，非空 `merchantSkuCode` 不重复；数据库同时保证系统内非空 `merchantSkuCode` 唯一。
- SKU 规格组合不重复，选择顺序不影响组合判定。
- 无规格商品只能有一个 SKU。
- 有规格商品的每个 SKU 必须为每个规格选择一个规格值。
- SKU 选择的规格及规格值必须存在于商品规格定义中。

### 创建流程

```text
ProductService.create(request)
├── preprocessed = ProductPreprocessor.preprocess(request)
├── validated = ProductValidator.validate(preprocessed)
├── pos = ProductPosCreator.mkPos(validated)
└── Tx.run(() -> ProductRepository.insert(pos))
```

预处理、校验和 PO 创建均在事务外完成；事务只包围数据库插入。

##### 构造约束

- `mkPos` 假定 Request 已完成预处理和校验。
- 每次调用只获取一次当前时间，所有 PO 共用该时间。
- `mkPos` 内生成所有内部 ID 和业务 Code，并写入固定初始值。
- 只创建并返回 PO，不执行校验或持久化操作。

### 持久化结果

#### `product`

创建 1 条记录。

| 字段 | 来源或初始值 |
| --- | --- |
| `id` | 系统生成 |
| `product_code` | 系统生成 |
| `status` | `DRAFT` |
| `title` | `title` |
| `subtitle` | `subtitle` |
| `description` | `description` |
| `category_code` | `categoryCode` |
| `primary_image_file_id` | `primaryImageFileId` |
| `version` | `0` |
| `created_at` | 当前时间 |
| `updated_at` | 当前时间 |

#### `product_gallery_image`

每个 `galleryImageFileIds` 元素创建 1 条记录。

| 字段 | 来源或初始值 |
| --- | --- |
| `id` | 系统生成 |
| `product_id` | 商品内部 ID |
| `file_id` | `galleryImageFileIds[]` |
| `sort_order` | 元素在数组中的下标 |
| `created_at` | 当前时间 |

#### `product_specification`

`specifications` 中的每个键值对创建 1 条记录。

| 字段 | 来源或初始值 |
| --- | --- |
| `id` | 系统生成 |
| `product_id` | 商品内部 ID |
| `specification_code` | 系统生成 |
| `name` | `specifications` 的键 |
| `status` | `ENABLED` |
| `sort_order` | 规格在有序映射中的位置 |
| `created_at` | 当前时间 |
| `updated_at` | 当前时间 |

#### `product_specification_value`

`specifications` 中每个规格值数组的元素创建 1 条记录。

| 字段 | 来源或初始值 |
| --- | --- |
| `id` | 系统生成 |
| `specification_id` | 所属规格内部 ID |
| `specification_value_code` | 系统生成 |
| `display_name` | `specifications` 对应规格值数组中的元素 |
| `status` | `ENABLED` |
| `sort_order` | 规格值在数组中的下标 |
| `created_at` | 当前时间 |
| `updated_at` | 当前时间 |

#### `sku`

每个 `skus` 元素创建 1 条记录。

| 字段 | 来源或初始值 |
| --- | --- |
| `id` | 系统生成 |
| `product_id` | 商品内部 ID |

| `merchant_sku_code` | `skus[].merchantSkuCode` |

| `image_file_id` | `skus[].imageFileId` |
| `version` | `0` |
| `created_at` | 当前时间 |
| `updated_at` | 当前时间 |

每个 `skus[].selections` 元素创建 1 条记录。

| 字段 | 来源或初始值 |
| --- | --- |

| `sku_id` | 所属 SKU 内部 ID |
| `specification_id` | `specification` 对应的规格内部 ID |
| `specification_value_id` | `value` 对应的规格值内部 ID |
| `created_at` | 当前时间 |

#### `stock`

每个 SKU 创建 1 条记录。

| 字段 | 来源或初始值 |
| --- | --- |
| `id` | 系统生成 |
| `sku_id` | 所属 SKU 内部 ID |
| `available_quantity` | `0` |
| `reserved_quantity` | `0` |
| `version` | `0` |
| `created_at` | 当前时间 |
| `updated_at` | 当前时间 |

- 类目和文件资源只保存引用，不创建新记录。
- 持久化顺序为：商品、轮播图、规格、规格值、SKU、SKU 规格选择、库存；空集合跳过批量插入。
- 以上数据在同一事务中全部成功或全部失败。
